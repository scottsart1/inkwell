# Inkwell

An S Pen-first note-taking app for large Android tablets (built for the Samsung Galaxy Tab S11 Ultra):
handwriting with a side-button eraser, PDFs, OCR, audio recording synced to notes, bring-your-own-key AI
(OpenAI, Anthropic, DeepSeek, Moonshot/Kimi), automatic `YYYYMMDD_Topic` file naming, and copies of
notes, transcripts and recordings in your Google Drive or on a private page on yourpitbox.com (the notes
vault) so you can read them on any computer, or one tap to email a note or transcript to your work address.

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for the code layout and [docs/GOOGLE_DRIVE.md](docs/GOOGLE_DRIVE.md)
for reading your notes on another computer (a work laptop, for example, including one that blocks Google),
and [docs/VAULT_API.md](docs/VAULT_API.md) / [web/notes-vault](web/notes-vault/README.md) for the notes vault.
